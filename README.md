# Таймер отдыха (AliceScreenSaver)

Android-приложение для детского планшета. Через заданное время пользования оно
закрывает экран надписью **«Отдохни»** и держит её, пока не пройдёт перерыв.
Настройки, выключение таймера и досрочное снятие блокировки доступны только по PIN-коду родителя.

## Как работает

- Время считается только когда экран включён и разблокирован.
- Когда лимит исчерпан, поверх всех приложений появляется экран отдыха с обратным отсчётом.
  Кнопки «Назад», «Домой» и «Недавние» его не убирают.
- За минуту до перерыва появляется подсказка «Через минуту перерыв».
- Если планшет пролежал выключенным дольше, чем длится перерыв, счётчик обнуляется.
- После перезагрузки таймер запускается сам, незаконченный перерыв продолжается.
- После 5 неверных попыток ввода PIN ввод блокируется на минуту (потом дольше).

## Установка

1. Откройте на планшете страницу [Releases](../../releases) и скачайте последний `AliceScreenSaver-*.apk`.
2. Разрешите установку из этого источника, когда Android спросит.
3. Откройте «Таймер отдыха», придумайте PIN.
4. В разделе «Разрешения» включите всё, особенно «Поверх других окон».
5. Задайте минуты и нажмите «Сохранить и запустить».

Новые версии ставятся поверх старой, настройки сохраняются.

## Сборка

Каждый пуш в `main` запускает GitHub Actions: APK собирается и выкладывается в Releases
и в артефакты прогона. Вручную сборку можно запустить на вкладке Actions → Build APK → Run workflow.

Локально: `gradle assembleRelease` (нужны JDK 17 и Android SDK), либо откройте проект в Android Studio.

APK подписывается ключом из `keystore/app.keystore`, чтобы обновления ставились поверх.
Репозиторий приватный; если сделаете его публичным, замените ключ и вынесите пароли в Secrets.

## Ограничения

Обычное приложение не может заблокировать Android полностью. Во время перерыва ребёнок может
опустить шторку уведомлений, а в остальное время — зайти в «Настройки → Приложения» и
остановить приложение принудительно. Чтобы закрыть эти лазейки, поставьте PIN на сам планшет,
не говорите его ребёнку и при желании ограничьте доступ к настройкам через Google Family Link.
